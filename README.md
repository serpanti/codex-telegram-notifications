# Codex Telegram Notifications

Скилл для уведомлений Codex в Telegram на Windows, macOS и Linux. Он отправляет результат завершённого хода, уведомляет о запросах к пользователю и позволяет задать отдельный вопрос с ответом в Telegram.

- Очередь SQLite сохраняется между запусками. Воркер повторяет доставку после сетевых сбоев.
- Токен бота и выбранный чат хранятся в системном хранилище учётных данных.
- Уведомления берут выдержки из задачи и результата. Перед настройкой выбери приватный чат и проверь, какие данные можно отправлять.

## Настройка

Склонируй репозиторий в папку `skills/codex-telegram-notifications` внутри домашнего каталога Codex. Понадобятся Python 3.11+ и отдельный бот Telegram. Запусти интерактивную настройку из корня репозитория:

```sh
python scripts/bootstrap.py
```

Команда создаёт отдельное окружение, устанавливает зависимости и предлагает локально ввести токен. Подробности о настройке и проверках есть в [SKILL.md](SKILL.md), [руководстве по установке](references/setup.md) и [описании сервиса](references/service.md).

Для офлайн-тестов выполни `python scripts/self_test.py` из настроенного Python-окружения.
